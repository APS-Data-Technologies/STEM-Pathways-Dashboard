# Start here

Open https://stem-pathways-dashboard.vercel.app/ for the deployed dashboard.

Use `README.md` to run the project, `docs/deliverables.md` to find the handover materials and `docs/progress.md` to see which acceptance actions remain. The integration branch is `feature/stem-dashboard` and the existing review is pull request 1.

In the downloadable handover package, `project/` contains source and cleaned data, while `deliverables/` contains the editable reports, user guide, demo deck and captioned backup walkthrough. Run `npm ci` and `npm run dev` inside `project/`.

Each teammate reviews the area assigned to their role, makes genuine corrections under their own account and contributes a personal reflection. Do not re-upload the whole application or claim someone else's commits. The lead collects the evidence and coordinates the sponsor review.
