# Project scope reference

This repository implements Option B, STEM Pathways Dashboard, for APS Data Technologies and Judson University. The supplied scope document and task workbook define tasks B-01 through B-61. The repository uses stage names for progress tracking.

Must-haves: cleaned public IPEDS STEM completions for one region; annual trend; field breakdown; institution view; field/year/degree filters; a public deployment and methodology page. Stretch items: filtered CSV, an institution map and checked findings. Required handover materials include the cleaning notebook, setup/rebuild/deploy documentation, test evidence, a one-page illustrated guide, demo script, editable slides, backup walkthrough and individual reflections.

The agreed team has four people. Product Owner and Frontend are combined under the lead; UX/UI and Data Visualization are combined under the design role. Each task has one named accountable owner in docs/task-board.csv.

A teammate review precedes merge. Sponsor decisions, real team meetings, demo delivery, personal reflections and ownership confirmation are external acceptance actions. The full task mapping and its evidence are in docs/progress.md.

Excluded: student-level records, accounts, database server, other regions, enrollment, cost, salaries, demographic breakdowns, forecasts, paid features and native apps.
